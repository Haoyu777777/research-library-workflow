# Changelog

## 0.1.1 — menu toggle fix

- Clicking an open More button or its arrow closes the menu across library, annotation, result and review pages.
- Escape and outside clicks dismiss menus; switching controls keeps only one menu open.
- Closing a view or disabling the plugin releases menu listeners.

## 0.1.0 — macOS alpha candidate

- Separate source-only distribution from the personal research vault.
- Standard plugin assets, embedded Help, first-run setup and a compact Home.
- Setup is explicit and requires an empty vault plus a compatible enabled PDF++.
- Existing collections are not migrated. Project metadata migration is limited to managed research records.
- Mac backups are opt-in; cloud AI and credentials are excluded. Manual transcription remains available.
- Preserves the reviewed source-linked result/question/review workflows, including source focus after annotation restoration.

This candidate has not been submitted to Obsidian's Community directory.
