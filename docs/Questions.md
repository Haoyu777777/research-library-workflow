# Questions

Write a question in the note where its context belongs. Its open/resolved state is separate from connections, pins and review-sheet selection.

## Write in an annotation or result

1. Open the annotation or saved result and choose **More → Write question**.
2. Type under **Questions to check**. An existing **Open questions** heading also works. Annotations already have a question section; the action adds the optional section to a compact result when needed.
3. When the section has meaningful text, **Open · Resolve question** appears beside it. An empty section hides the control.

You can type directly in an existing section. Opening a note from the file explorer, an internal link, or the library controls uses the same behavior. Markdown and LaTeX work in question text.

## Resolve, reopen, or revise

Click **Resolve question** when you are satisfied. The text stays in its note, and the control becomes **Resolved · Reopen question**. Choose **Reopen question** to reverse the state.

Editing resolved question text automatically reopens it for review. Clearing the question text hides the control; it does not delete the annotation, source highlight or result.

The current control applies to the whole question section in that note. Several questions written in one section share one state. Use separate notes when you need to track them independently.

## Find open or resolved questions

Use **Home → Open questions**, or **Search and review → Review view → Questions**. In **Filters**, choose **Question state → Resolved** or **All states** to include resolved material. Broaden the project filter if needed.

A project review sheet shows questions only from notes you selected for that sheet. Use **More → Add to review sheet** on the note, or **Review sheet → Choose items → Save selection**. A selected question disappears from the open-question part after resolution; its original text remains in the note. Mathematical key items can keep their main card while the question is resolved.

## Connect a question to a saved result

Open the saved result → **More → Connect results** → select the annotation under **Related questions** → **Save connections**. The result shows **Related questions**; the annotation shows **Related results** linking back.

This picker currently lists annotation question sections. A question written inside a saved result is tracked in that result; it is not a separate annotation entry. A connection keeps its own selection when a question is resolved. See [[Help/Result connections|Connections]] for removal and missing targets.

**Resolve question** changes review state. **Connect results** creates a relationship. **Add to review sheet** chooses what a project displays. Use the action that matches the task you want to do.
