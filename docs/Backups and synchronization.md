# Backups and synchronization

Local backups are off by default. To enable them, open Settings → Research Library Workflow → Open setup and turn on Local backups. The backup command creates a ZIP and hash manifest in Documents/Research Library Backups, outside the vault, and can run daily while enabled. The directory contains your research; keep it private. This command is validated on macOS only.

To restore, close the vault, extract a backup into a separate folder, and open that folder as a vault. Check PDFs and notes before using it as your working copy. Plugin credentials are not included: cloud AI is not connected in this alpha.

Synchronization is supplied by your chosen external service. Research Library does not upload a vault or certify synchronization completion. Keep files locally available, close and finish syncing before switching devices, and avoid simultaneous editing of a shared PDF. Do not put a vault inside a web download ZIP and expect it to synchronize automatically.
