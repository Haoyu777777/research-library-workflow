# Manual transcription

Cloud AI is unavailable in this alpha. No AI account or paid credits are needed.

1. Open a source annotation and choose Transcribe passage to LaTeX.
2. Type or paste the statement using Markdown and LaTeX.
3. Choose Preview math, then Save transcription draft.
4. Compare the draft with the source before marking its transcription checked or accepting it. A transcription check does not verify the mathematics.
