# Set up your research library

This macOS alpha uses a new, empty, dedicated vault. Existing collections are not migrated.

1. Create a new empty vault in Obsidian.
2. Install and enable PDF++ through Settings → Community plugins. Version 0.40.31 is the tested integration. Enable native PDF editing through PDF++ if you want standard PDF highlights; Research Library enables deletion confirmations when its integration starts.
3. Install the Research Library Workflow release, enable it, and open its welcome.
4. Review setup and choose Create my research library. Local backups are optional.
5. Open Home and choose Add a paper. Review metadata before saving. Use the default Research project or create your own.

Import/download metadata may contact arXiv, Crossref and other source services when requested. Private drafts stay local. Cloud AI is disabled in this alpha.

A PDF placed in the vault waits for metadata confirmation; it does not silently create a paper note. Exact duplicate imports reuse the existing source. New versions must be kept separate when their mathematical content changes.

## Open a configured vault

Open this complete research vault in Obsidian and use Home. Enable Research Library Workflow and PDF++. A copied alpha plugin alone does not contain papers or a configured library.

## Correct metadata or incomplete BibTeX

Open a paper note and choose More → Update bibliography. Review the metadata and source/version match, inspect Proposed filenames, then Confirm update. Use Additional citation fields under Edit details and sources for venue, volume, issue or pages. Unknown fields remain unknown until verified.
