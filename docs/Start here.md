# Help

Start with a paper, keep your thoughts beside its source, and save the mathematics you want to reuse. Use the task guides below whenever you need a reminder.

> [!info] macOS alpha
> This is the free, local-first distribution alpha. Cloud AI and existing-library migration are not enabled.

Reading, annotation writing, search and result notes work without an AI sign-in. If opening the library on another Mac, start with [[Help/Library setup#Open a configured vault|Open a configured vault]].

## Your first reading session

1. Open [[Home|Library]], find a paper by title or author, and choose **Read PDF**.
2. Select a passage and choose **Add research comment**, or press **⌘⇧M**.
3. Write in **My thoughts**. The annotation keeps a source image and **Open original passage** link.
4. For a definition or theorem you will reuse, choose **More → Save a result** in the annotation.
5. Return through [[Help/Search and review|search]], a [[Help/Project review|project review sheet]], or your [[Help/Result connections|connections]].

## What each item means

| Item | Purpose |
| --- | --- |
| Paper note | Your notes about one saved paper/version, with its metadata and PDF. |
| Annotation | Your thoughts about a specific highlighted passage or PDF page. |
| Saved result | An editable definition, lemma, theorem, or proof idea with its source. |
| Project | A group of papers, results, annotations and project writing. A paper can belong to several projects. |
| Question | Text in a note's question section, with an open/resolved state. |
| Pin | A personal reminder to revisit an item. |
| Review-sheet selection | An explicit choice to show an item on one project's curated sheet. |
| Connection | A link between results, or between a result and an annotation question. |
| Citation list | The subset of sources cited by a particular piece of writing. |

These choices are independent. Resolving a question keeps its note. Unpinning, removing a connection, or removing a review-sheet selection also keeps the note. Deleting an annotation is a separate action that can remove its linked PDF mark.
