# Reading and writing

Use the common page toolbar for primary actions and More for additional actions. Native Obsidian Outline follows note headings. Use Obsidian Settings → Appearance to choose light or dark mode.

Keep general paper thoughts under Notes. Each passage has its own annotation with source image/link, thoughts and questions. Results separate the statement, your work and its source. Add optional questions or adaptation sections when needed.

Write Markdown and standard LaTeX using Obsidian’s editor. Built-in commands work without another plugin. See [[Help/Math commands|Math commands]] before using custom macros.
