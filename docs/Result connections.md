# Connections

Use connections to follow your argument between saved results and to link questions with the result they concern. You choose the relationships.

## Connect one result to another

1. Open the result whose work uses another saved result.
2. Choose **More → Connect results**.
3. Under **Uses**, check the saved definitions, lemmas or theorems used in this work.
4. Choose **Save connections**.

The starting result shows **Uses**. Opening a linked result shows **Used by**, pointing back. Statements are not copied, and a connection does not change mathematical verification or transcription status. Only accepted saved results are offered as new Uses targets.

## Connect an annotation question to a result

1. Write the question under **Questions to check** in its annotation.
2. Open the saved result and choose **More → Connect results**.
3. Find the annotation under **Related questions**, check it, and **Save connections**.

The result shows **Related questions**. The annotation shows **Related results** linking back. One entry represents that annotation's question section. Open and resolved questions can both be connected. They do not need to be selected on a project review sheet first.

Search the popup by result/annotation title, question text, notation, source paper or author. Each question entry includes its source/page, open/resolved label and a short preview. Older notes work automatically. A blank annotation question section is not offered.

## Change or remove a connection

Reopen **Connect results** on the owning result, change the checkboxes, and **Save connections**. **Cancel** keeps your saved choices. Follow a related-result link from an annotation to reach the result that owns the selection.

Unchecking removes the relationship in both directions. It keeps the notes, their writing, question states and PDF highlights. There is no need to delete either note to remove a connection.

## What happens when notes change

Renaming a note keeps its links. A deleted target is shown as unavailable; restoring that original note restores the link. A different note at the old filename does not inherit the relationship. If a linked question section becomes empty, its existing connection remains labeled accordingly. A result returned to suggestions is labeled **Needs acceptance**.

If the popup says a selection changed while open, cancel and reopen it to use the current choices. Ambiguous duplicate identities require review rather than an arbitrary match; see [[Help/Troubleshooting|Troubleshooting]].
