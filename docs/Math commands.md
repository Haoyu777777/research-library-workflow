# Math commands

Standard Markdown math uses Obsidian’s built-in MathJax. For example, write `$\lambda_2<1$` or `$$\lVert Av\rVert \leq \lambda\lVert v\rVert.$$`.

This alpha does not install a global custom-macro extension or copy another user’s preamble. If you need custom commands, configure a compatible math extension yourself. For portability use standard LaTeX commands in shared notes.
